# Proyecto 1 Renzo - Casa de 1 Piso

Este proyecto contiene el diseño técnico, memoria de cálculo, cuadro de cargas, selección de conductores y protecciones térmicas/diferenciales para una **vivienda unifamiliar de un piso** con 2 circuitos derivados.

## Estructura del Proyecto
- `proyecto.yaml`: Archivo de configuración canónico del proyecto.
- `datos/parametros-proyecto.yaml`: Parámetros eléctricos y ubicación.
- `documentacion/memoria_de_calculo.md`: Memoria de cálculo detallada CNE, fórmulas y verificaciones.
- `entregables/informe_tecnico_completo.md`: Informe final para revisión técnica.
