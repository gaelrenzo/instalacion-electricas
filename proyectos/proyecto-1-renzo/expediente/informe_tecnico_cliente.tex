\section*{2. Cálculo Simplificado y Calibres Recomendados}

Para garantizar un trabajo seguro y duradero, la instalación se dividirá en **2 circuitos derivados independientes**:

\subsection*{Circuito C-1: Alumbrado (11 Luminarias + 8 Interruptores)}
\begin{itemize}
    \item \textbf{Potencia LED (15 W a 20 W):} $P = 11 \times 20\,\text{W} = 220\,\text{W}$.
    \item \textbf{Consumo de corriente:} $I = \frac{220\,\text{W}}{220\,\text{V}} = 1.0\,\text{A}$ (Carga pequeña).
    \item \textbf{Conductor propuesta:} **2.5 mm² Cu (N.° 12 AWG)** (Fase + Neutro + Tierra).
    \item \textbf{Protección (Breaker):} **10 A** Monofásico.
\end{itemize}

\subsection*{Circuito C-2: Tomacorrientes (29 Tomas)}
\begin{itemize}
    \item \textbf{Carga estimada simultánea:} $P = 3,000\,\text{W}$ (Refrigerador, TV, PC, electrodomésticos).
    \item \textbf{Corriente de demanda:} $I = \frac{3,000\,\text{W}}{220\,\text{V}} = \mathbf{13.64\,\text{A}}$.
    \item \textbf{Conductor propuesta:} **2.5 mm² Cu (N.° 12 AWG)** (Fase + Neutro + Tierra).
    \item \textbf{Protección (Breaker):} **20 A** Monofásico + **Diferencial 25 A / 30 mA**.
\end{itemize}

\begin{tcolorbox}[colback=BgGrey,colframe=DarkBlue,title=\textbf{Nota Importante sobre el Cable N.° 14 (2.08 mm²)}]
    No recomiendo usar cable N.° 14 AWG para los circuitos derivados de esta instalación nueva. Se utilizará como mínimo **2.5 mm² Cu (N.° 12 AWG)** para asegurar mayor capacidad, evitar calentamientos y garantizar la regla de seguridad:
    $$\mathbf{I_{\text{demanda}} \le I_{\text{breaker}} \le I_{\text{conductor}}}$$
\end{tcolorbox}
